# Dar Libre

Site de réservation de logements au Maroc (projet n° 10, module M233 – Développement Web).

- Recherche par ville ou nom, filtre de prix maximum et tri
- Calendrier interactif en JavaScript (dates réservées désactivées)
- Calcul automatique du prix total (nuits, ménage, taxe de séjour)
- Formulaire de réservation avec validation
- Galerie de photos avec zoom et localisation Google Maps

Technologies : HTML, CSS, JavaScript (aucune bibliothèque externe).
